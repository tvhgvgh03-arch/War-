# راهنمای راه‌اندازی بات جنگ جهانی

بات کاملاً با دکمه کار می‌کنه؛ فقط `/start` یک‌بار لازمه تا منو باز بشه.

## ۱. ساخت بات و گرفتن توکن
1. به [@BotFather](https://t.me/BotFather) پیام بدید → `/newbot` → اسم و یوزرنیم انتخاب کنید.
2. یک توکن مثل `123456789:AAExxxxx...` می‌گیرید — این رو نگه دارید.

## ۲. گرفتن آیدی عددی خودتون (برای ادمین شدن)
به بات [@userinfobot](https://t.me/userinfobot) پیام بدید تا آیدی عددیتون رو بگیرید.

## ۳. اجرای محلی (تست روی سیستم خودتون)
```bash
pip install -r requirements.txt
export BOT_TOKEN="توکنی که از BotFather گرفتید"
export ADMIN_IDS="آیدی_عددی_شما"
python bot.py
```
اگه چند ادمین دارید، آیدی‌ها رو با کاما جدا کنید: `export ADMIN_IDS="111,222"`

## ۴. هاست رایگان روی Railway
1. یک ریپوی گیت‌هاب بسازید و فایل‌های `bot.py` و `requirements.txt` رو داخلش بذارید.
2. وارد [railway.app](https://railway.app) بشید و با گیت‌هاب ثبت‌نام کنید.
3. New Project → Deploy from GitHub repo → ریپوتون رو انتخاب کنید.
4. در تب Variables اضافه کنید:
   - `BOT_TOKEN` = توکن بات
   - `ADMIN_IDS` = آیدی عددی شما
5. اگه لازم شد در Settings یک Start Command با مقدار `python bot.py` تنظیم کنید.

⚠️ چون دیتابیس SQLite (`game.db`) روی دیسک موقت Railway ذخیره می‌شه، با هر ریدیپلوی ممکنه پاک بشه.
برای بازی طولانی‌مدت بعداً می‌تونیم اون رو به یک دیتابیس دائمی (مثل Railway Postgres) منتقل کنیم.

## ۵. نحوه‌ی کار بازی (همه چیز با دکمه)

### برای بازیکن‌ها
- بازیکن `/start` می‌زنه → دکمه‌ی **📩 درخواست کشور** رو می‌بینه.
- روش می‌زنه، اسم دلخواه کشورش رو می‌فرسته → درخواست خودکار برای شما (ادمین) ارسال می‌شه با دکمه‌ی تایید/رد.
- بعد از تایید شما، بازیکن با دکمه‌ی **🌍 وضعیت کشور من** همه‌چیز رو می‌بینه.
- با **🎖 ساخت نظامی** یکی از دسته‌های موشک/جنگنده/زمینی رو انتخاب می‌کنه، بعد واحد مشخص رو، بعد تعدادش رو تایپ می‌کنه.
- با **🏙 ساخت شهر/معدن** شهر یا معدن طلا/آهن/نفت می‌سازه و اسم دلخواه بهش می‌ده.
- با **⚔️ حمله** آیدی عددی هدف رو می‌فرسته و حمله انجام می‌شه.

### برای شما (ادمین)
دکمه‌ی **👑 پنل مدیریت** فقط برای آیدی‌های داخل `ADMIN_IDS` نشون داده می‌شه و شامل:
- **📥 درخواست‌های در انتظار** — لیست کسانی که منتظر تایید کشورن (یا مستقیم وقتی کسی درخواست می‌ده پیام با دکمه‌ی تایید/رد براتون میاد)
- وقتی تایید می‌کنید، جمعیت کشور رو خودتون به‌صورت عدد وارد می‌کنید (کاملاً دستی)
- **💰 اعمال سود روزانه برای همه** — هر بار که بزنید، بر اساس شهر/معدن‌های هر بازیکن بهش سود می‌ده. **هیچ محدودیتی نداره**، هر چندبار که بخواید توی روز می‌زنید.
- **🎁 افزودن منبع به بازیکن** — آیدی بازیکن، بعد نوع منبع (پول/نفت/آهن/طلا/جمعیت)، بعد مقدار
- **📋 لیست بازیکنان** — لیست همه (زنده/نابود)
- **🗑 حذف بازیکن**

## ۷. اضافه کردن قابلیت جدید در آینده (مثل نیروی دریایی)
کد طوری نوشته شده که برای اضافه کردن یک دسته‌ی جدید (مثلاً دریایی) کافیه:
1. یک دسته‌ی جدید داخل دیکشنری `UNITS` در بالای `bot.py` اضافه کنید (مثلاً `"navy": {...}`) با واحدهاش (ناوشکن، زیردریایی و...).
2. یک اسم فارسی براش داخل `CATEGORY_NAMES` بذارید.
بقیه‌ی بات (منو، ساخت، محاسبه‌ی قدرت حمله/دفاع، نمایش وضعیت) خودکار باهاش کار می‌کنه، نیازی به تغییر جای دیگه‌ای نیست.
همین‌طور برای ساختمان جدید، فقط یک آیتم به `BUILDINGS` اضافه کنید.
